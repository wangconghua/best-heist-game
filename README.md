The Gilded Vault is a top-down stealth heist game: sneak Rook the burglar through three museum rooms, read the guards' vision cones and the sweeping security cameras, lift the Star of Meridia, and slip out the getaway door. Every room offers several routes — the guarded hall, the cover of the display cases, or a hidden vent — and smoke pellets and camera jammers are the tools that buy a few seconds of nerve. It plays offline in a desktop browser, keyboard and mouse, with no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD or arrows move, Shift sneaks, E grabs loot and picks locks, 1 drops a smoke pellet, 2 fires the camera jammer, and clicking the floor walks there.
